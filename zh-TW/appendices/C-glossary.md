## 快速參考 — 八個核心術語

以下八個術語幾乎出現在每一章中。此處的譯注僅為便利查閱；正式條目請見 GLOSSARY.md。

| 術語 | 繁體中文 | 簡要定義 |
|---|---|---|
| design intent | 設計意圖 | 硬體*應該*要做什麼 — 設計者腦中的模型，以明確方式陳述。 |
| RTL (Register-Transfer Level) | 暫存器轉移層級 | 描述可合成硬體的抽象層級：每個時脈週期對暫存器執行運算並傳遞資料。 |
| assertion | 斷言 | 對預期行為的可驗證陳述。違反時由模擬器或形式化工具回報。 |
| property | 性質 | 跨越一個或多個時脈週期的時序陳述，在特定時間點可成立或失敗。 |
| sequence | 序列 | 描述跨越一個或多個時脈週期的信號事件樣式，作為性質的建構單元。 |
| implication | 蘊涵 | `\|->`（重疊）或 `\|=>`（非重疊）運算子：「若前提匹配，後件必須成立。」 |
| vacuity / vacuous pass | 空真 / 空泛成立 | 當斷言的前提（antecedent）從未為真時，斷言在不進行任何實質檢查的情況下通過。使用 cover 性質可診斷此問題。 |
| formal verification | 形式化驗證 | 以數學方法證明性質在所有合法輸入及所有可達狀態下均成立，無需模擬。 |
